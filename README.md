# Upselling v3 · guestapp prototype

Interactive prototype of the guest upselling flow (extras, early check-in / late check-out, partners, pets, cart and requests) inside the redesigned Chekin guestapp, for mobile and desktop.

Open **[flows.html](https://dclemares.github.io/upselling-v3/flows.html)**:

- Pick a screen with Prev / Next or from **Deal settings** (title, highlight, description, photos, confirmation type, «Already purchased» and «In the cart» flags).
- Versions: **Final · mobile + desktop** and **Vlad feedback** (counter from production, email step for deals that need approval, extras in the cart, new list titles, no shadows on desktop). The left column «What changed» opens each change before / after.
- View as **Mobile + desktop** (both frames stay in sync: a click in one is mirrored in the other), Mobile only or Desktop only.

Static site, no build step: everything is plain HTML/CSS/JS with demo data.
